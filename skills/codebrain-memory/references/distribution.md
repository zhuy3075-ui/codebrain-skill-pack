# 分发与路径配置

安装本技能或更换 Vault 路径时读取本文件。

## 首次使用

1. 用户先在 Obsidian 中新建一个专用 Vault，并记下完整绝对路径。
2. 将整个 `codebrain-memory` 技能目录复制到 `~/.codex/skills/codebrain-memory`，保留内部资源；已有技能先比较和备份。
3. 新开会话，确认本技能可见。
4. 用户把 Vault 完整路径告诉本技能；需要初始化时明确提出初始化要求。
5. 检查路径有效后，将 `assets/vault-template/` 内缺失的文件复制到 Vault 根目录，保留已有内容和 `.obsidian/`。
6. 检查 Vault 索引和项目模板的六个核心文档，报告使用路径与验证结果。

## 路径选择

优先级依次为用户当前明确路径、当前项目已确认且可访问的路径、`CODEBRAIN_HOME`、已存在的 `~/CODEBRAIN`。缺少首次路径时先询问；明确路径无效时先修正；没有明确选择且候选路径冲突时询问。

用户只告知路径时，先只读检查。聊天中的路径不等于永久配置，后续可以再次提供或由用户自行配置 `CODEBRAIN_HOME`。不要自行修改环境变量、全局协议或创建符号链接。

只有用户明确选择不用 Vault 时，才使用项目内 `docs/codex/<task-slug>/`。

## 更换路径

迁移需要用户明确要求。先确认源路径、目标路径及已有内容，再复制并验证文件完整性；验证完成前保留原目录。更新路径配置需要相应授权，不在仅整理技能包时迁移用户的真实记忆库。

可复用技能和共享提示词只使用通用路径示例。面向用户的说明和交接默认使用简体中文。
