# Agents 索引

## 默认边界

- Codex 维护项目核心状态。
- 其他 AI 工具可以把原始材料投递到收件箱。
- 人类保留目标选择、风险接受、合并、部署、发布、回滚、密钥、账单、生产数据和 L3 无人值守放行。

## 投递路径

| 来源 | 允许路径 | 备注 |
| --- | --- | --- |
| Codex | 项目核心文件 | 用证据维护状态 |
| 其他 AI | `00_Inbox/raw/` 或项目 `_inbox/` | 仅原始材料 |
| 人类 | 自行选择 | 人类是负责人 |

## 默认禁止

- 密钥或凭据。
- 生产私有数据。
- 未验证的长期结论。
- 静默删除或迁移。
