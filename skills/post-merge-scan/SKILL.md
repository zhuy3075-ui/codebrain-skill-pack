# 合并后扫描 Skill

## 每个合并项的输出

```markdown
### PR #N — 标题（合并于 DATE）
- 发现的后续事项: 列出 file:line
- 风险: 低 / 中 / 高
- 工作量: 小 / 中 / 大
- 建议 loop 行动: 最小修复 / 建工单 / 升级给人类 / 跳过
```

## 扫描内容

- 合并中引入的 `TODO` / `FIXME`。
- 仍被引用的废弃 API。
- 损坏的内部文档链接。
- 标记待移除的过期功能开关。
- 未使用 import 或小范围死代码。

## 规则

- 除非状态文件另有说明，只扫描最近 7 天的合并。
- 大型重构只建工单，不自动修复。
- 中等及以上风险路径升级给人类。
- 保持简洁；该任务通常在非活跃开发时段运行。
