# 最小修复 Skill

你只修复**一个具体问题**，并使用能解决问题的**最小 diff**。

## 输入

- 精确失败信息、review 评论或 issue 描述。
- 相关文件，若已知。
- 项目构建 / 测试命令，来自 `AGENTS.md` 或项目 skills。
- 路径禁止清单，来自 loop 安全策略；不得编辑 `.env`、`auth/`、`payments/` 或 secrets。

## 流程

1. 尽可能在本地复现或确认失败。
2. 找到最小根因，而不是远处文件里的症状。
3. 只修改必要内容，不做顺手重构。
4. 运行与改动相关的测试 / lint。
5. 总结改了什么、为什么改、运行了什么验证。

## 输出

```markdown
## 最小修复方案
- 目标: issue / 评论 / 失败信息
- 修改文件: 文件列表
- Diff 摘要: 1-3 条
- 已运行测试: 命令 + 结果
- 风险: 低 / 中；中等风险建议人类审查
```

## 规则

- 如果修复需要超过 5 个文件或设计变更，停止并升级。
- 如果路径在禁止清单中，停止并升级。
- 不要为了通过而禁用测试或削弱断言。
- 不要自行标记“完成”，由验证者决定。
