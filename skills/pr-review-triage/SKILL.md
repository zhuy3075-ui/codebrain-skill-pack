# PR 审查分拣 Skill

对每个被观察的 PR，输出：

## 单个 PR 输出

```markdown
### PR #N — 标题
- CI: 通过 / 失败；失败时列出 job 名称
- 审查: 已批准 N 个 / 要求修改 / 无
- 阻塞评论: 列出可行动评论
- 是否可合并: 是 / 否；说明原因
- 建议 loop 行动: 无 / 最小修复 / rebase / 升级给人类
```

## 规则

- “可合并”必须满足项目策略里的全部必需检查和批准。
- 不可行动的小意见只记录，不启动修复。
- PR 闲置超过 4 天，建议交接给人类。
- 高风险标签（安全、破坏性变更）一律升级给人类。
